User Guide

Complete, runnable examples for both sides of Celery Cloud. The code of every example is a real file in pages_source/examples/ of the repository; the server examples are exercised by the test suite.

The examples share one scenario: a small calculator and a text report, written as local tasks (packaged with the runner) plus one remote task (an existing Lambda function).
