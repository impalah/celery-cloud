Chords

The group and counter items that Celery’s DynamoDB backend keeps for chords.

Backend items that Celery uses to run groups and chords.

Celery’s DynamoDB backend keeps two kinds of items next to the task results, in the same table and with the same id hash key:

  • b'celery-taskset-meta-<group id>': written by the client when it starts a chord, it lists the ids of the header tasks (result holds the JSON of the group result).

  • b'chord-unlock-<group id>': a counter (chord_count) that every header task increments when it finishes; the one that reaches the size of the group runs the chord body.

The runner reads and updates them exactly as Celery’s worker does.
